# ⏳ Time Traces | A Journey Through History

**Time Traces (ردّ زمان)** is an educational website that takes visitors on a journey through important periods of world history.

🌐 **Live Website:** [Visit Time Traces](https://nastaranwahabzada-cloud.github.io/T-TRAWEL/)

💻 **GitHub Repository:** [T-TRAWEL](https://github.com/nastaranwahabzada-cloud/T-TRAWEL)

---

## 📖 About the Project

Time Traces is a history-themed website designed to help visitors explore different historical periods through a simple and engaging interface.

Visitors can start from the homepage, choose a historical period, and navigate to its dedicated section to discover historical information.

The project was developed as a final group project using HTML, CSS, and JavaScript.

## 🎯 Project Goals

- Introduce important periods of world history.
- Organize historical information into separate sections.
- Make learning history easier and more enjoyable.
- Provide simple and clear website navigation.
- Create an interactive and responsive user experience.
- Practice teamwork and collaborative web development.

## 🏛️ Historical Sections

The website includes the following sections:

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/nastaranwahabzada-cloud/T-TRAWEL.git
```

2. Open the project folder in Visual Studio Code.

3. Make sure the original folder structure is preserved.

4. Open the root-level `index.html` using the Live Server extension.

5. Explore the website through its navigation cards and links.
